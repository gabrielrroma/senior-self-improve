# Product

## Register

product

## Users

This is a personal productivity app for one primary user managing daily tasks, focus sessions, points, streaks, achievements, and self-defined rewards on a local machine. The user is usually in a task flow: planning the day, checking what is pending, completing work, reviewing progress, or redeeming rewards.

## Product Purpose

Rotina Diaria exists to make a daily routine visible, motivating, and easy to keep. Success means the user can quickly add tasks, complete them, earn points, review progress, keep a streak, use Pomodoro focus, and spend points on rewards without friction or fear of losing local data.

## Brand Personality

Calm, motivating, and practical. The product should feel like a focused personal command center: encouraging without being childish, structured without being heavy, and warm without becoming decorative.

## Anti-references

Avoid a marketing landing-page feel, oversized decorative heroes, gamification that looks childish, noisy dashboards, one-note color themes, and interactions that hide standard controls behind novelty. The app should not feel like a generic SaaS template or a dopamine-heavy habit game.

## Design Principles

- Preserve the routine first: every screen should make the next useful action obvious.
- Make progress tangible: points, streaks, goals, and achievements should be easy to scan.
- Keep motivation quiet: feedback should encourage the user without interrupting the work.
- Protect existing habits: migration work must preserve features, data contracts, and familiar navigation.
- Prefer local reliability: the app should stay simple to run through the existing Python server.

## Accessibility & Inclusion

Target WCAG AA contrast for normal text, keep all core actions reachable by keyboard, preserve visible focus states, support reduced-motion preferences, and avoid relying on color alone to communicate task priority, status, or reward availability.
